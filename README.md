# SfM-Interactive-Virtual-Tour
3D Scene Reconstruction and Virtual Tour created for CS436. Implements a simplified Structure-from-Motion pipeline to recover camera poses, build a sparse 3D point cloud, and render an interactive virtual tour from multi-view images.
### Instructions on running it:
1. open folder CS436_Visualization
2. open terminal within web_viewer
```
cd web_viewer
```
3. go into broswer and input: python -m http.server 8000
4. look at controls and browse!
